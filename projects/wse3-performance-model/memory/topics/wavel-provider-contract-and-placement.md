# Wavel provider contract and placement modeling

- Wavel adoption is baseline-first: freeze measured/manual witnesses before asking Wavel/KAIR to own search or legality.
- Provider contracts must preserve identity between pricing and materialization. Template revisions, source revisions, direct/composed materialization, bounded extrapolation, and coverage status are explicit provenance fields.
- Placement-aware communication templates are semantic candidates selected before benchmark matrices; PERegion v1 is rectangular, while multi-shard/irregular placement is future work.
- Batch size is a performance-model input axis separate from storage slots; first compute-profile matrices focus on decode-only Qwen3-1.7B/4B anchors with planned sparse configurations.
